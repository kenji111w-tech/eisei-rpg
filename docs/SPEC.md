# 衛生管理者RPG（仮題）仕様書 v0.2

作成：Claude（2026-11-22）
状態：ユーザーが3点を決定済み（1本で第1部・第2部／主人公は会社の総務の新人／見た目は乙4と同じ作りで色だけ変える）

## 1. 目的
- 乙4 RPGと同じ仕組みで、衛生管理者試験に合格できるRPGを作る。仕組みは「教えてから問う」「にがてのまとめ」「出題メーターと80%ルール」「模試」「合言葉」「事件の謎」。
- 第1部で第二種、第2部（有害業務）まで進めば第一種の範囲をすべて学べる。

## 2. 試験の形（2026-11-22 に公表情報で確認）
| 区分 | 科目・範囲 | 問題数（配点） |
|---|---|---|
| 第二種 | 関係法令（有害業務を除く） | 10問（100点） |
| 第二種 | 労働衛生（有害業務を除く） | 10問（100点） |
| 第二種 | 労働生理 | 10問（100点） |
| 第一種 | 関係法令（有害業務） | 10問（80点） |
| 第一種 | 関係法令（有害業務以外） | 7問（70点） |
| 第一種 | 労働衛生（有害業務） | 10問（80点） |
| 第一種 | 労働衛生（有害業務以外） | 7問（70点） |
| 第一種 | 労働生理 | 10問（100点） |
| 特例第一種 | 関係法令（有害業務）・労働衛生（有害業務） | 各10問（各80点） |

- 五肢択一式。試験時間は第一種・第二種とも3時間、特例第一種は2時間。
- 合格：科目ごと（第一種で範囲が分かれている科目は範囲ごと）に40%以上、かつ合計60%以上。
  - 乙4（科目ごと60%）とちがうので、模試の判定はこの基準にする。
- 第二種でなれるのは、有害業務と関わりの少ない業種（情報通信業、金融・保険業、卸売・小売業など）の衛生管理者だけ。第一種はすべての業種。

## 3. 主人公と舞台
- 主人公：「ハタラク商事」の総務部に入った新人。
  - 会社が大きくなり、常時50人以上の事業場になるため、衛生管理者を選ばなければならなくなった。
  - 部長に「君が資格を取ってくれ」と言われるところから始まる。
- 舞台：会社の中と、「働く人の国」（夢の中の世界）を行き来する。
  - 現実の会社で困りごとが起きる → 夢の国で魔物（病気・けが・ルール違反）を倒して知識を得る → 会社で解決する。
- 第1部：オフィスの国（第二種の範囲）。第2部：工場の国（有害業務。第一種の範囲）。
- 第1部のあとで「第二種のエンディング」か「第2部へ進む」かを選べる（乙4の火の国と同じ形）。

## 7. 乙4 RPGから引き継ぐもの
- 教えてから問う仕組み、用語の先出しチェック、選択肢の長さチェック。
- にがてのまとめ、出題メーター（80%でボスに挑戦）、未出題を中心にした特訓。
- 合言葉（ひっかけの見抜き方）、事件の謎と手がかり、ボスのうそ。
- 模擬試験：第二種30問・第一種44問・特例第一種20問。合格判定は「範囲ごと40%・合計60%」。
- 音楽、メニューの説明、タップで進む、斜め移動、iPhone／Androidアプリ化（Capacitor）。

## 8. 見た目
- 乙4と同じ作りで、色だけ変える。
  - 基調色：緑（緑十字・安全衛生のイメージ）と白。乙4の赤・オレンジとは別のゲームとわかるようにする。
- タイトル画面は乙4と同じ形で、色とタイトル文字を変える。

## 9. 出典の方針
- 法令：e-Govの条文（労働安全衛生法・同施行令・労働安全衛生規則・労働基準法・事務所衛生基準規則・有機則・特化則・酸欠則・粉じん則・石綿則・電離則・じん肺法など）で確かめる。
- 指針・ガイドライン：厚生労働省の公表資料（情報機器作業、腰痛予防、熱中症、THP、受動喫煙、ストレスチェック）。
- 過去の公表問題は、出題の傾向をつかむためだけに使う。文章はそのまま使わず、問題はすべて自分で作る。
- 問題データには「どの時点の法令か（基準日）」を記録する。

## 10. 法改正メモ（作るときに反映する）
- 令和7年法律第33号（令和7年5月14日公布）：労働安全衛生法などの改正。施行は主に令和8年4月1日。
- 50人未満の事業場のストレスチェック：令和10年4月1日から義務（それまでは努力義務）。
- ストレスチェックの集団分析の方法の見直し（令和9年4月1日施行）。
- 熱中症の報告体制と手順の整備：令和7年6月1日から事業者の義務。
- 試験は改正の施行後しばらくしてから反映されることが多いので、問題には「改正前・改正後」を書き分ける。

## 11. 作る順番
1. エンジンの移植（設定の外出し、色、タイトル、試験の形）
2. 第1部：S1〜S4 → K1〜K4 → E1〜E4（町ごとに授業と問題、合言葉、魔物、ボス）
3. 第2部：Y1〜Y4 → Z1〜Z3
4. 模試（第二種・第一種・特例第一種）
5. 物語（事件の謎）、エンディング
6. テストと確認（Gemini／ChatGPTの確認、ユーザーのiPhone確認）

## 12. 問題数の目安
- 町ごとに40〜60問、全体で800〜1,000問。模試専用の問題を別に用意する。
