# 衛生管理者RPG ～働く人の国～（試作品）

第一種・第二種衛生管理者試験の合格を目指す、ドラクエ型のブラウザRPG。iPhoneのホーム画面に追加して遊ぶ。乙4 RPG と同じ作り（エンジン）で、色と中身を衛生管理者向けにしたもの。

公開ページ：https://kenji111w-tech.github.io/eisei-rpg/

## 中身
- 主人公：会社の総務の新人。夢の中の「働く人の国」を旅する。
- 第1部（第二種の範囲）：労働生理（S1〜S4）→ 関係法令（K1〜K4）→ 労働衛生（E1〜E4）。E4のボスのあとで、エンディングを見るか第2部へ進むかを選べる。
- 第2部 工場の国（第一種の有害業務）：労働衛生・有害（Y1〜Y4）→ 関係法令・有害（Z1〜Z3）。Z3のボスのあとにエピローグとスタッフロール。
- 出題範囲：72項目（労働生理16・関係法令15・労働衛生16・有害業務の労働衛生13・有害業務の関係法令12）。どの問題も、ゲームの中で先に教えてから出す。
- 問題：1094問（練習794・模試専用300）。
- 戦闘：クイズ形式。こちらの攻撃も敵の攻撃も問題で決まる。
- 試験センター（タイトル画面）：
  - 第二種：関係法令10・労働衛生10・労働生理10の30問・3時間（本番・全体・弱点・再挑戦）
  - 第一種：44問・3時間・400点満点（有害業務の範囲は1問8点）
  - 特例（有害業務の範囲だけ）：20問・2時間・160点満点
  - 本番模試は6回分。合格の目安は、科目（範囲）ごとに40%以上かつ合計60%以上。

## 起動方法
- GitHub Pages：main の直下（/）を公開している。
- 手元で試す：`python3 -m http.server` を実行し、`http://localhost:8000/` を開く（ファイルを直接開くと問題データを読めない）。

## データの作り方（tools/）
- 問題：tools/eq_*.py（町ごと・模試ごと）を編集して `python3 tools/eisei_q.py data/questions.json`
- 地図と物語：tools/eisei_story.py を編集して `python3 tools/eisei_world.py`
- 人物・合言葉・出題範囲：`python3 tools/eisei_chars.py`
- 点検：check_data.py（不整合）／check_taught.py（教える前に問う問題）／check_terms.py（用語の先出し）／check_length.py（正解だけが長い選択肢）
- 選択肢の差し替え：tools/fix/ に FIX を書いて `python3 tools/rechoice.py tools/fix/xxx.py`（選択肢の順番は変えない）
- 動作確認：tools/slice.py 町（その町のボスまで自動で進める）／tools/examtest.py '第一種' 1（試験センターを通しで解く）

## バックアップ
役所またはタイトルの「バックアップ」から、ファイルまたはテキストで書き出し・読み込みできる。Safari版とホーム画面版はデータが別なので、移すときはこの機能を使う。
