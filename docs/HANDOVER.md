## 4. 作り方
- 世界：`cd tools && python3 eisei_world.py`（eisei_story.py に物語・ステージ・魔物・技）

- 仲間・合言葉・出題範囲表：`cd tools && python3 eisei_chars.py`
- テスト：ポート8766でサーバーを立てて `python3 tools/slice.py`
