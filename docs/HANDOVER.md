# 引き継ぎメモ（衛生管理者RPG）

新しいチャットで続けるときは「docs/HANDOVER.md を読んで続けて」と伝えてください。
最終更新：2026-11-22（v0.1.0-proto）

## 1. 概要
- 衛生管理者試験（第二種→第一種）を学ぶRPG。乙4 RPG（kenji111w-tech/otsu4-rpg）のエンジンを移植して作っている。
- 仕様書：docs/SPEC.md（ユーザーが決めたこと：1本で第1部・第2部／主人公は会社の総務の新人／見た目は乙4と同じ作りで色だけ変える）。

## 2. ユーザーとの約束（乙4と同じ）
- 返事は日本語。毎回、最後に時刻を書く。
- 4時間ごとに、正直に進み具合を報告する。
- 「作業を止めて下さい」と言われるまで作業を続ける（send_later で続きを予約）。
- 教えてから問う。魔物の名前で中身がわかるようにする。タップでどこでも進む。
- 公式サイト（e-Gov など）を読む許可はもらっている。
- 個人的な事情は、公開リポジトリに書かない。

## 3. 今の状態
- エンジンの移植：物語・仲間の加入と離脱・町の到着・ボス後の文・科目の割り当て・技の効果を world.json のデータで決められるようにした（乙4のコードも残してある）。
- 保存領域のキーは eiseirpg:（乙4と混ざらない）。
- できた町（9つ・問題335問・魔物41体の絵）：
  - 労働生理：S1 ミャクの町（血液・心臓・免疫・凝固）、S2 イキの町（呼吸・代謝・消化・肝臓）、S3 シンケイの町（神経・自律神経・感覚・筋肉）、S4 リズムの町（腎臓・ホルモン・体温・睡眠とストレス）。仲間はセイリ（S4の後で離脱）。
  - 関係法令（有害業務以外）：K1 センニンの城下町（衛生管理体制）、K2 ケンシンの城下町（健診・面接指導・ストレスチェック）、K3 ジムショの城下町（事務所衛生基準規則）、K4 ロウキの城下町（労働基準法）。仲間はホウキ（K4の後で離脱。第2部の法令で再加入の予定）。
  - 法令の数字は e-Gov の条文（安衛法・安衛令・安衛則・事務所則・労基法）で確認してから問題にした。
- テスト：tools/slice.py（引数なし＝最初からS3まで、`slice.py K4` などで、その町だけを前の町クリア済みの状態から）。各町ボスまでエラーなし。
- 次：労働衛生（有害業務以外）E1 カンキョウの森（温熱・採光照明・換気と必要換気量）から。仲間はカンキ（world.base に用意済み）。そのあと E2〜E4、第2部（Y1〜Y4・Z1〜Z3）、模試、エンディング。

## 4. 作り方
- 世界：`cd tools && python3 eisei_world.py`（eisei_story.py に物語・ステージ・魔物・技）
- 問題：`cd tools && python3 eisei_q.py ../data/questions.json`（eq_*.py に町ごとの問題）
- 仲間・合言葉・出題範囲表：`cd tools && python3 eisei_chars.py`
- テスト：ポート8766でサーバーを立てて `python3 tools/slice.py`
